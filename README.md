Jewel Quest — это увлекательная головоломка в жанре Match-3, где вам нужно собирать кристаллы в ряды по 3 и более штук, чтобы набрать очки и пройти уровни. Игра оснащена специальными кристаллами с уникальными способностями, таблицей рекордов и приятным визуальным оформлением.
[table-6c33727e-93a6-4574-9986-ca2efebd624c.csv](https://github.com/user-attachments/files/26370858/table-6c33727e-93a6-4574-9986-ca2efebd624c.csv)
Функция,Описание
🎮 2 режима игры,По времени (набери максимум очков) и по очкам (достигни цели)
💣 3 специальных кристалла,"Бомба, Линейный и Радужный с уникальными эффектами"
📊 Таблица рекордов,Сохранение лучших результатов с именами игроков
🎵 Звуковые эффекты,Фоновая музыка и звуки для всех действий
🎨 Анимации,"Плавное перемещение, падение и исчезновение кристаллов"
📱 Адаптивный интерфейс,Розовая цветовая схема в стиле Jewel Quest
